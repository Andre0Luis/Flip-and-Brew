# Flip & Brew

App de bem-estar digital em React Native (Expo SDK 56). A pessoa deixa o celular virado para baixo, uma xícara de café vai se enchendo em tempo real e o tempo offline vira moedas para a loja de cosméticos. Estoicismo e antifragilidade fazem parte da mensagem do app.

O projeto está em reconstrução. O código anterior (planta, widget do Z Flip, loja antiga) está no histórico do git, a partir do commit `f056731`.

## Rodar

```bash
npm install
npx expo run:android
```
