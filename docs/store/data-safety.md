# Google Play · Segurança dos dados (rascunho)

Respostas sugeridas para o formulário “Segurança dos dados”. Confira com o app final antes de enviar.

| Pergunta | Resposta | Motivo |
| --- | --- | --- |
| O app coleta ou compartilha dados do usuário? | Não coleta dados que saiam do aparelho. | Tudo fica no MMKV local. Não há conta, servidor nem análise. |
| Dados são criptografados em trânsito? | Não se aplica. | Nada é enviado. |
| O usuário pode pedir a exclusão dos dados? | Sim. | Ajustes › Apagar todos os dados, ou desinstalar. |
| Compras no app? | Sim, quando ativadas. | Processadas pela Google Play e pelo RevenueCat. Habilitar a coleta “Informações de compra” e “Identificadores de dispositivo ou outros” se o RevenueCat estiver ativo. |
| Permissão especial: Acesso ao uso (`PACKAGE_USAGE_STATS`) | Declarar, com justificativa. | Lê desbloqueios e tempo de tela do dia para o painel Bem-estar. Opcional, só no aparelho. Pode exigir o formulário de permissões sensíveis. |

Classificação etária sugerida: livre, sem conteúdo sensível.
